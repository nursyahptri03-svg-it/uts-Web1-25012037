## Deskripsi

Aplikasi Pemesanan Kantin Kampus adalah aplikasi berbasis web
yang dibuat menggunakan PHP, HTML, dan CSS.

Aplikasi ini digunakan untuk melihat menu makanan dan minuman,
mencari menu, memilih kategori, serta mengelola keranjang pesanan.

## Fitur

1. Menampilkan daftar menu.
2. Mencari menu berdasarkan nama.
3. Memfilter kategori makanan dan minuman.
4. Menambahkan menu ke keranjang.
5. Menghapus item pesanan.
6. Mengosongkan keranjang.
7. Menghitung subtotal pesanan.
8. Memberikan diskon 10% untuk subtotal minimal Rp50.000.
9. Menampilkan total pembayaran.
10. Menyimpan keranjang menggunakan session.
11. Menyimpan kategori favorit menggunakan cookie.

## Teknologi

- PHP
- HTML
- CSS
- Visual Studio Code

## Cara Menjalankan

1. Instal PHP pada komputer.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Buka terminal di Visual Studio Code.
4. Jalankan perintah:

   php -S localhost:8000

5. Buka browser.
6. Masukkan alamat:

   http://localhost:8000

## Catatan

Aplikasi ini menggunakan array PHP sebagai data menu
dan session untuk menyimpan keranjang.

Aplikasi ini belum menggunakan database MySQL.#
